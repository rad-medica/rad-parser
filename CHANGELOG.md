# Changelog

## Unreleased

### Fixed

- **Deflated Explicit VR Little Endian (1.2.840.10008.1.2.1.99)** and JPIP
  Referenced Deflate: the Data Set is inflated (PS3.5 A.5) with a bundled,
  synchronous RFC 1951 decoder in every runtime; before, only the File Meta
  Information was returned. `write()` can produce deflated files (stored
  blocks, even-length padding). `inflateDicom()` gives the byte layout that
  offsets refer to.
- **VR UN (PS3.5 6.2.2)**: a UN element whose tag is in PS3.6 is decoded with
  the registered VR as Implicit VR Little Endian, whatever the Transfer
  Syntax (Rescale Intercept stored as UN now reads -1024 instead of raw
  bytes); undefined-length UN is read as an Implicit VR LE sequence.
- **DA / TM / DT** are returned as stored text. Before, nested values were
  converted to JS `Date` with today's date in UTC (a Radiopharmaceutical
  Start Time of "090000" became "2026-11-17T09:00:00.000Z").
  `parseDate`/`parseTime`/`parseDateTime` now return the stored components
  (`{ year, month, day }`, `{ hours, minutes, seconds, fraction }`, ...) and
  never create a `Date` (breaking change for callers of these helpers).
- **Implicit VR** files use a VR registry generated from PS3.6 2026d
  (`scripts/generate_vr_dictionary.py`) instead of a hand-written list of ~60
  tags, so sequences and numeric values in implicit files are decoded.
- Values are decoded the same way at the top level and inside sequences
  (nested OB/OW were `number[]`, nested strings were split into arrays).
- Explicit VR length layout follows PS3.5 7.1.2 (OV, SV, UV have 32-bit
  lengths); SV/UV are decoded as `bigint`.
- Big Endian: only word VRs (OW, OF, OL, OD, OV) are byte-swapped; OB pixel
  data is no longer swapped.
- Sequences of undefined length are walked structurally; the parser no longer
  scans for the delimiter byte pattern (PS3.5 7.1.2).
- **Anonymizer** applies the full Basic Profile of PS3.15 Table E.1-1 (656
  attributes, generated by `scripts/generate_anonymization_rules.py`),
  recursively in sequences. "X" actions now remove the attribute (they were
  ignored), tag lookups are case-insensitive (Study/Series Instance UIDs were
  not replaced), Institution Name is removed by default, and new UIDs are
  valid 2.25 UIDs (PS3.5 B.2). `actionOverrides` resolves compound actions
  per tag.
- Writer: encapsulated Pixel Data is written with its Basic Offset Table, AT
  values as 16-bit pairs, BE swap by VR word size, DS within 16 characters,
  long values of 16-bit-length VRs as UN.
- WASM: fixed a type error that broke the `rad-core-wasm` build, an `i8`
  overflow in the RLE decoder for 128-byte literal runs (PS3.5 G.3.1), and
  the loaders' use of wasm-bindgen's `init()` result.
- `extractRescaledPixelData` reads attributes from the elements and handles
  unaligned views.
- `docs/api.md` had unresolved merge-conflict markers; rewritten.

### Added

- Pixel Data locations for lazy frame access: `dataOffset` on every element;
  for encapsulated Pixel Data `basicOffsetTable` and `fragments`
  (`{ offset, length }`, absolute). Shallow mode reports them too.
- `pixelData: "view" | "copy" | "skip"` parse option. The default is now
  zero-copy views; encapsulated `Value` no longer contains the Basic Offset
  Table as its first entry.
- `tests/integration/synthetic_evaluator.test.ts`: comparison with
  dicom-parser and round-trip checks over a directory of radspider synthetic
  files (`RAD_PARSER_SYNTH_DIR`), and `benchmarks/synthetic_compare.ts`.
- Committed synthetic fixtures (`tests/fixtures/synthetic`, no patient data)
  replace the missing `test_data/` directory in the integration tests.

### Changed

- Full parse is ~2–3x faster than 2.0.0 on the synthetic corpus (no
  per-call copy of the input, no pixel copies by default, one dictionary per
  data set).
- A raw Data Set without a VR field is reported as Implicit VR Little Endian.
- `normalizeTag` lower-cases hex digits to match parsed keys.
- `type-check` covers `src/` and the build scripts used by `package.json`
  (`rootDir` made every run fail); stale debug scripts in `scripts/` are not
  type-checked.
